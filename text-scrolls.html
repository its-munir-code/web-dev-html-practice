Understanding HTML Concepts

HTML (HyperText Markup Language) serves as the standard skeleton for constructing web pages across the entire internet.

It uses structured elements and tags to define content types such as headings, images, forms, and paragraphs effectively.

Modern HTML5 introduces semantic elements that provide web browsers and search engines with a clear context regarding the site's layout.

Text Formatting & Semantics

When formatting text, using the <b> "tag applies visual bolding" simply to draw the eye without conveying extra urgency, whereas using the <strong> "tag indicates structural importance" and alerts screen readers to emphasize crucial content.

Similarly, the <i> "tag displays italic styling" for idiomatic terms, technical labels, or foreign words, while the <em> "tag stresses verbal emphasis" to change the linguistic tone and rhythm of a sentence.

Self-closing tags like <br> allow us to create explicit line breaks within a single block,
which is ideal for poems, short notices, or multiline structural items.
Meanwhile, thematic breaks like <hr> visually separate distinct sections.
